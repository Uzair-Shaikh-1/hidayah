# Hidayah

Hidayah is a full-stack web application built with the MERN stack.

This project was built as part of my journey to understand how the different parts of a full-stack application work together — from the backend and database to the frontend and user interface.
---

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Other
- REST APIs
- JWT Authentication
- Git & GitHub

## ✨ Features

- User-friendly and responsive interface
- Full-stack functionality using React, Node.js, Express.js, and MongoDB
- REST API integration between frontend and backend
- MongoDB for storing and managing application data
- User authentication and protected functionality
- Responsive design for different screen sizes
- Dynamic data displayed through the frontend

---

## 📚 What I Learned

Hidayah was more than just another project for me.

One of the biggest things I learned was how the **frontend, backend, and database actually communicate with each other**.

Instead of looking at each part separately, I got to work with the complete flow:

```text
User
  ↓
Frontend
  ↓
API Request
  ↓
Backend
  ↓
MongoDB
  ↓
Backend Response
  ↓
Frontend
  ↓
User
